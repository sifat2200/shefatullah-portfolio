# Md. Shefatullah Bin Sadik — Personal Portfolio

A modern portfolio built with Next.js, TypeScript, Framer Motion and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Deploy

Push the project to GitHub and import the repository into Vercel.

## Personalization

- Replace the `SBS` avatar in `app/page.tsx` with a real profile image if desired.
- Add a real CV PDF under `public/` and connect it to a Resume button.
- Replace the LinkedIn short link with your preferred permanent LinkedIn URL.
- Add GitHub/project repository URLs to the project cards.
- Add additional certificates and achievements as they become available.

## Source

The content was structured from the uploaded CV and prior project information supplied in the conversation.
